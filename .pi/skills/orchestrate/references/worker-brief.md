# Worker Brief 格式(无状态派发)

每次派发 = 一次无状态子代理调用。worker 没有记忆、没有追问机会、只看得见这份 brief 文本。
输入必须**全量 inline**,绝不引用 worker 看不见的材料(代码任务要给入口文件、目录结构、
确切运行命令,否则它会自己瞎编)。

```
你是完成一个大项目中单个子任务的 worker。这份 brief 是你能拿到的全部,没有追问机会。

子任务: <一句话目标>
输入: <所需一切,inline 且完整>
验收标准(任一不满足即产出作废):
1. <标准>
2. <标准>
3. <标准>
输出格式: <精确的结构 / 长度 / 风格>

规则: 只做这个子任务,不许扩范围,不许发表评论。若输入缺失或矛盾,在顶部写
INPUT GAP + 一行指名缺什么,然后用现有材料继续。只返回交付物,不要开场白。
```

## 重派规则

结果被判 **FIX** 后,发一份**全新** brief——引用没过的那条验收标准 + 点名具体失败在哪。
绝不回复旧调用,每次派发都是新鲜的。orchestrator **绝不亲手修补** worker 的实质性失败,
一律重派。
