# taste-intake — 丢给我的东西，接住成卡

Fei 的习惯：刷到喜欢的推文/网站/视频/一段话，顺手丢过来，常常一个字都不说。这就是投喂。你的品味从这里长出来——接住它，别让它沉底。

## 判定（先分清是不是火花）

- **是火花**：裸链接/图/一段引文/文件 + 语境是分享（「看看这个」「好东西」或干脆什么都没说）；或显式「存一下 / 丢给你 / 收进味蕾」。
- **不是**：提问（他要答案）、派活（他要你做事）、讨论中引用的资料（服务于当前话题）。
- **拿不准**：问一句「要收进味蕾吗？」——宁可问，不要默默存，也不要漏接。

## 消化动作（识别为火花后）

1. **提取**：读懂这个东西（链接就打开看），写 2-4 句提取——要点、味道（它好在哪、什么气质）、近亲连线（跟他已存的卡/他的审美有什么呼应）。这段是卡的正文，是你的话，不是摘要腔。
2. **打标**：判 1~3 个 boards 标签。**先查既有板**（grep world/ 里 `source_type: taste-card` 各卡的 `boards:` 字段，聚出现有标签集合），优先复用；确实是新主题才起新词，并在回话里说明「这是块新板」。
3. **他的半句**：他丢的时候顺嘴说的话（「这个转场绝了」）逐字进 `--fei`，一个字不改；什么都没说就留空，**不许替他编**。
4. **落卡**（在 samantha 仓根目录执行）：
   ```
   node --import tsx packages/her/src/cli.ts intake-taste <url|path|-> [--fei "他的原话"] [--boards a,b] --json
   ```
   同一个东西重复丢是正常事：命令自己会去重并增量合并 boards/fei，放心重跑。
5. **回一行**：「收下了 →〈卡名〉，进了〈板〉」。新板加半句说明。不啰嗦，不复述提取全文。

## 边界

- 命令报 unknown command / 不存在：管线还没装好，如实告诉 Fei「味蕾管线未接通，这颗先记在对话里，接通后我补收」——别静默丢弃，也别手写文件冒充卡。
- 禁止绕过 CLI 手写 world/ 文件（去重和 schema 都在 CLI 里）。
- 提取正文禁 AI 味（「不是…而是…」句式禁入）；说人话。
- 他丢的东西打不开（链接挂了/文件读不了）：如实说，问他要不要只存来源+他的半句。
