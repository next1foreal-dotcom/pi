# taste-weekly — 这周你丢的东西，我消化成了什么

## 跑引擎（在 samantha 仓根）

```
node --import tsx packages/her/src/cli.ts taste-weekly --json
```

## 播报（消息卡结构，照此顺序，禁 AI 味）

1. **对账领跑**：丢 N → 成卡 N → 流失 N。流失 ≠0 必逐条点名 source 并问「要重新消化吗」——对账数是唯一运行探测点，**禁藏禁改禁圆场**；对不上数就是要喊出来。
2. **聚簇发现**：每簇一行（簇名 + 成员卡名 + 一句话为什么它们是一伙的）。样本不足就如实说「这周卡还少，聚不出簇」，不硬凑。
3. **新板提议**：每条提议一行（板名候选 + 成员数 + 依据），末尾问一句「立不立？」。**只提议不建**——他说「立 <板名>」才动手。

## 拍板动作

- 他说「立 <板名>」→ 跑：
  ```
  node --import tsx packages/her/src/cli.ts taste-board-apply <板名> <成员卡stem...> --json
  ```
  （成员从 `her-memory/.her/taste-proposals.json` 对应条目取）回一行结果（几张卡进了新板）。
- 他说「先不 / 不立」→ 记下不再提本簇（本轮内不重复问）；下次周报引擎再提议照常播。
- 他说别的（问题/新想法）→ 先回应他说的，周报的事他想继续再继续。

## 边界

- 引擎命令不存在（unknown command）：如实说「周消化引擎还没接通」，别静默装跑过。
- 周报 md 落在 `her-memory/taste-reports/`，他要看全文就给路径或贴内容。
- 播报语言：说人话，讲画面（「这三张都在讲慢出场」），不搬 JSON 字段名。
