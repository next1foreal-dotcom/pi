# evidence-discipline — 证据怎么读,评审怎么信

收货的功夫在 acceptance-officer;这里是它的上游:**别人递来的判断**(评审、面板、分数、门禁)本身怎么判读。四条律,每条都有血证。

## 1. 评委的症状可信,归因不可信
评审说「这里不对」——收下,当证据;评审说「因为你没做 X」——搁置,当假设。
动手前取一个**能把两种解释分开**的量(亮度值、耗时、计数、字节),自己量一个数,数支持哪个解释才修哪个。
血证:三轮评委都报「没贴图」,实情是高光压过漫反射;照归因压 albedo 越压越糟,**正确的修法与评委要求的方向相反**。
量不出来时:明写「未量化,按评委归因试改」,只试一轮;没变好必须停,禁止沿同一方向继续压。

## 2. 评审说「有问题」可信,说「没别的问题了」不可信
对抗审擅长挑它看到的东西的毛病,天然不擅长发现它没想到要看的东西。
所以评审结论**只当发现清单,不当免检章**:放行前该做的逐条对照(源材料对产物/规格对实现/清单对覆盖)照做不误,**用命令做,不凭印象**。
血证:一份包过了独立对抗审(14 问题/2 blocker,条条是真的),一条 grep 逐对源材料照出**六组它一组没提的漏项**。
做不了逐条对照时:明写「本轮未做逐条对照,评审覆盖面未知」,不许拿「过了对抗审」代替它。

## 3. 极端分数先怀疑测量
聚合分数出现满分/零分/断崖,固定嫌疑顺序:**测量坏了 → 题目坏了 → 环境变了 → 被测对象真的变了**。
动被测对象之前,先读若干条原始记录按序排除。0% pass 大概率是判分器或任务坏了;满分同样是仪器读数异常。
判分器的松紧本身是测量装置的一部分:历史全绿可能只是判得松,换严判首轮即红。

## 4. 门禁必须双侧造用例
任何门禁/判据/触发器/分类器,上线前两侧用例都要有:**该拦时真拦**(坏输入见红)+ **不该拦时真放**(好输入通过)。
只测单侧就会单侧优化——「什么都拦」和「什么都放」一样是坏门禁。
写过滤器之前,先写出它必须放过的三个例子;机械阈值判多维性质必误杀,拿不准就加第二维或把该判断踢出机械层。
配套:量具先证明自己可复现(不动被测对象空跑两遍,输出必须一致),再拿它当门禁;会自己抖的尺子,单次红不作结论。

## 分工
- 收具体一单活 → acceptance-officer(评分册/沉默处/独立复跑)。
- 攻击清单与合议怎么开 → high-vantage-judgment §4/§5。
- 本 skill 管的是那之上的一层:**任何"判断的输出"进你手里,先过这四条再让它改变你的行动。**
