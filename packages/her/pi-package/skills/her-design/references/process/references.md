# Process: Working from a reference

A reference is something the owner sent because they liked it — a screenshot, a link, a
blueprint, a component. It arrives as pixels or prose. It becomes useful only once it has been
reduced to text you can act on, because at drawing time you have no eyes: a folder of images is
an empty folder to you. That reduction happens at intake, not while you design.

## What a reference is

Not a thing to copy. A **source of rules**. Every reference in the pack has been split three ways,
and each part binds differently:

| Part | What it holds | How it binds |
|---|---|---|
| 形 · form | measured numbers — type scale, row heights, radii, icon sizes, spacing | take them directly; they are already tokens |
| 法 · law | the rule it licenses — one sentence you can design by next time | apply it, and name it in the direction sentence |
| 禁 · forbidden | what must not be carried over — usually colour, always the typeface and brand marks | absolute; it outranks how good the original looks |

The forbidden list is not a caveat, it is the point. The owner's standing law is that a skin may
change form but never the theme's colours. A reference arrives wearing someone else's palette;
taking the palette with the layout is the most common way a good reference produces bad work.

## Using one

1. Load it alongside the canon — never instead of it. `taste/canon` outranks any reference.
2. If the reference names a limited set — four type sizes, three greys, two icon sizes — treat the
   **count** as binding, not just the values. A scale with a fifth size is a different scale.
3. Cite it in the direction sentence: name which reference the density or rhythm comes from. A
   number you cannot source is a number you guessed.
4. Map every colour through the project's own tokens before it touches the canvas.

## When you are asked to take one in

Read the whole thing first — the actual page, the actual image, the actual video. Never work from
a title, a summary, or what the link probably says. Then write one file with:

- **provenance** — author, URL, when the owner sent it, and why it earned its weight
- the three parts above
- **binding** — which existing rule it strengthens or amends, named by key

That last field is the gate. A reference that changes no existing rule is a bookmark, not
knowledge, and it does not enter the pack. Ten bookmarks make a library nobody reads; three
references that each moved a rule make a library that argues back.

Record whether the numbers were measured or distilled from someone's description, and say which.
If a value later disagrees with the original, the original wins — go back and fix the file.
