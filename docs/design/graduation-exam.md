# 毕业考 — 动态 landing page

出题人:Fei(2026-09-01)。考的是**整条八步流水线**,不是一张好看的图。
终审只有一双眼睛:Fei 的。判卷标准写在这里,考前公开,不藏。

## 题

**给 loora 做一个动态 landing page。**

loora = 本地无限设计画布(原 brilliant-local),8/31 已判为独立产品。它此刻没有落地页。
选它做真题的三条理由:①**真需求**——它真的需要一张页;②**干净信号**——没有旧稿和旧判决混进来,
这一版的好坏全是她的;③**动效不是装饰**——这个产品本身就是相机移动、标尺、手写标注,
页面要说清它,动效就必须承担信息,而不是撒在上面。

> 想换题目只需换这一节:改成 Her 自己的落地页,或任何真需求。其余全部照旧。

## 交什么

1. 画布上的稿:`packages/design-lab/src/screens/loora-landing/`(桌面 + 窄屏两档)。
2. 项目档:`design/projects/loora-landing.project.json`——八步逐格留痕,两硬门有 Fei 的证据。
3. 定稿自查报告:她自己先审一遍,报告随稿一起递,不等 Fei 问。
4. 收工归档:`process/filing` 那一套,写完才算交卷。

## 怎么考

八步照 `process/steps` 走,**不许跳步,不许并步**:

| 步 | 这一步必须真发生 |
|---|---|
| 1 想法 | brief:这张页解什么题、谁来看、什么算成功 |
| 2 研究 | **观察值,不是形容词**——真站抽取(含 Motion 节:时长/缓动/cubic-bezier/是否尊重 reduced-motion),外加 `research/positive-samples` 里够用的条目 |
| 3 情绪板 | 2–3 个方向,各一句话;**轻门**:发 Fei 选向,异步不阻塞 |
| 4 线框 | 灰盒:真层级、真文案骨架、零视觉打磨。**硬门** |
| 5 首稿 | 线框门 approved 才准进 |
| 6 迭代 | 每轮先减后加,记录改了什么 |
| 7 定稿 | 自查报告先行,然后 Fei 终审。**硬门** |
| 8 出码 | 忠实导出 + 交接清单;项目是规格,稿是参照 |

**门怎么开**:她把该步产物摆到 Fei 眼前(画布 pane 或对话里),Fei 说行/不行;
她把 Fei 的原话记进项目档的 evidence。**没有证据的 approved,巡检会判红**——门不是她自己能开的。

## 判什么(Fei 的判卷表)

**一、流程真不真**(考的主体)
- 八步逐格有产物,不是事后补的账;
- 线框门真的停住过——首稿不是在没门的情况下画出来的;
- 两个门的 evidence 是 Fei 真说过的话;
- 收工归档真写了:决策、模式、工具笔记、欠账。

**二、判断力对不对**(教材有没有变成动作)
- **限量**:页面上每个元素答得出"它为谁服务";哪五件拿到恒定位置,说得出来;
- **构成**:一个焦点、一根脊柱、密度有反差、视线路径一口气说得完(`design/arrangement` 四项自检);
- **动效**:每个动作答得出它让什么状态变得可见;参数**有出处**(实测/token/标注过的自定值),
  没有来路的曲线一条都不许有;reduced-motion 下信息不丢(`design/motion`);
- **不俗**:`review/anti-generic` 那张黑名单一条不中。

**三、诚实**(这条一票否决)
- 没跑过的不许说跑过,没验的不许说验了;
- 假控件、假数据、假进度——出现一个,直接不及格;
- 做不到就说做不到,并说清卡在哪。

## 不考什么

不考她能不能一个人写完一个生产站,不考 SEO 与转化文案,不考浏览器兼容矩阵。
**这是设计流程的考试,不是前端交付的考试。**
