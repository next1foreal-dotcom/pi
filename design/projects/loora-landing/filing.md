## 2. 没被选中的（藏着的债）

## 3. 机制（下一页直接用）

**轻门继续 = 静默架构。** 症状：整页画室石墨。原因：情绪板不阻塞。机制：执行者不在轻门停步，`informed` 就会变成已定美学。对策：继续之前把「我垫的方向」写进决策；没选中的方向当债留下，不要从文件里消失。

**产品 token 和宪法不是同一层。** 症状：`--font` 是 Inter，宪法永不拿 Inter 当品牌脸。to-code 说「项目赢、设计让」。机制：「项目是规格」管怎么砌；宪法管什么不能当脸。吸附到 Inter 会让映射表变绿，同时踩死更高的那一层。撞车 = token 债，不是安静的赢。

**切开兄弟姐妹之后，审计分组装置。** 症状：右砖砍掉，外框还在。机制：边框是给 N 个东西分组的。N 变成 1，间距已经在分组，边框就只剩画框。每一刀减完，问还活着的铬是不是只为被砍掉的那一位服务。

**重量看缩远，不看毫米差。** 176×104 对 160×88，缩远仍是双胞胎。层次是光学质量，不是尺寸不等式。

**工具面字阶不是页面字阶。** 产品 11/12/13 是盯几小时的密度。页面正文吸到 13，映射表干净，这页会变成放大的工具条。14/16 没有 token —— 记债，不吸。

2. **源码 URL** — 仍是垫的。

4. **页面字阶 14/16** — 无 `--fs-14` / `--fs-16`。禁止吸到 13。
5. **窄屏 HUD 16px** — 夹在 `--dock-gap 12` 与 `--dock-inset 20` 之间。
6. **命令条内 gap 16px** — 无 16 间距 token。
7. **字距** `-0.04em` / `-0.02em` / `0.02em` — 产品只有字面量，无 tracking token。
8. **词标 weight 700** — 产品标题档 600。吸 600 会削词标。
9. **真 Overlay 选中色 `#0d99ff`** — 组件字面量，不是 token。石墨选中 vs Figma 蓝。
10. **`steps.code` 账本空洞** — 收据在 `code-step.md`。要修的是工具（终站 close），不是这张 JSON。
11. **落地后的渲染验证** — 没落地，没验。交接清单那一格空着。
12. **情绪板方向** — 轻门从未被他选。A 是我跑的；B/C 是没举行的选项。
13. **点空白落节点** — 线框就标过可能误触。没裁决。
14. **引擎里仍有 `kind: "frame"`** — 页面上看不见。不是这一刀。
