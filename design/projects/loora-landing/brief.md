## 我垫的默认值(可翻)

1. 页面文案语言:中文为主,专有名词/命令/快捷键保留英文原文(Fei 沟通偏好:默认简中,不搞双语并排——双语并排在他的禁单里)。
2. 命令入口:`npm install && npm run dev`(README 今日真实入口)。
3. 源码链接:真实 remote `github.com/next1foreal/brilliant-local`(仓库 URL 以 Fei 定稿为准,页面标「待定」)。
4. 品牌名「loora」以小写词标呈现(当前产品无 logo;词标只做文字,不发明图形):
5. 首屏结构(已被 Fei 2026-09-01 打回推翻):原垫「左脊柱文字 + 第二屏产品帧」是在「讲」loora。Fei 同意把「页面即产品」揉进来——首屏就是一块能拖、能缩、能落节点的画布,文案退成边上的小字。
6. 「无遥测」声明以产品真实状态为准(源码无 analytics 库、AboutPage 自述 no telemetry),页面采用「无回传——源码可查」措辞,不替它背书未来。
