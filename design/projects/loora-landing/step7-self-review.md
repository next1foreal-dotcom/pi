# loora landing — step 7 自审

2026-09-03。对着重拍帧 `design/stills/loora-landing-top.png` 写，不是对着代码。终门是 Fei 的，本文件只把这一轮付过的账记下。

## 构成（对着帧）

- 焦点：缩远仍是中央那块选中砖。标题、源码、命令条都在耳语。
- 脊柱：HUD 挂四角；簇内部左缘对齐（砖与文案同 x），不是把短句居中到砖底下。
- 密度：画布开、HUD 密而小。簇靠 20px 空隙成组，没有画框代劳。
- 眼路：词标 → 主张 → 中央真节点 → 底栏命令。

## 这一轮付的账

| 决策 | 机制，不是症状 |
|---|---|
| 砍 n-frame | 右砖砍掉之后外框只剩画框，间距已经在分组。边框是失败的分组手段，不是第二种焦点。 |
| 不把文案居中到砖下 | 短句跟砖同左缘 = 一条脊柱。对称居中是模板默认，这页不需要纪念碑。 |
| 文案留下 | 它是第二种真节点（text），不是砖的标签。底栏提示管操作，它管「落下来的是节点」。 |
| 默认选中砖 | accent 只允许出现在「本机运行」和选中四角。种子选中是 10% 确认档，不是装饰高亮。 |
| 不加第二刀 | 帧上没有第二个没挣到位置的东西。再动就是打磨，不是构成。 |
